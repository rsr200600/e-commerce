THE USEFUL BITS

A few quick answers.

How much is shipping? ＋

In this demo, shipping is free on orders of ₹1,499 or more and ₹99 below that. You can edit this rule in assets/js/cart.js.

Can I return something? ＋

The storefront displays a 7-day return-window message for demonstration. Add your real return policy before accepting customer orders.

Does the checkout accept real payments? ＋

No. This is a frontend project only. Checkout simulates placing an order in your browser; it does not charge a card or send an order to a server.

Can I edit products and prices? ＋

Yes. Update the product catalogue in assets/js/main.js. For a production site, use a database and a protected admin API.
